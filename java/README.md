# Java 学习笔记

本目录共 10 篇，按入门顺序编排：00 篇是学习总纲，01 到 09 篇按知识点分类。整体路线是先把语法和面向对象打牢，再往上走常用 API、集合与函数式编程，最后到异常、IO、并发、网络和反射这些进阶话题。

## 学习路线

| 阶段 | 篇目 | 目标 |
| --- | --- | --- |
| 语法入门 | 01 - 02 | 能写出带分支、循环、数组和方法的基本程序 |
| 面向对象 | 03 | 能用类和对象描述业务，理解封装、继承、多态三大特性 |
| 基础类库 | 04 - 05 | 熟练使用常用 API、日期时间和三大集合 |
| 进阶语法 | 06 - 07 | 会用 Lambda 与 Stream，能正确处理异常和文件读写 |
| 高阶主题 | 08 - 09 | 理解并发与网络，看懂框架底层的反射和代理 |

## 笔记特点

- 第 00 篇的总纲建议最先读，它交代了整套笔记的组织逻辑和阶段自查标准。
- 每个语法点先给可运行的例子再解释规则，避免一上来就堆概念。
- 面向对象、集合、并发这三块是后面 JavaWeb 和框架的地基。
- 每篇开头都有学习目标与前置知识，能看出这一篇依赖哪些前置篇目。

## 阅读建议

1. 00 篇先看一遍，建立整体印象，不必记住细节。
2. 01 到 03 必须按顺序读并动手敲，这是所有后续内容的前提。
3. 04 到 05 的常用 API 和集合是日常写代码用得最多的部分。
4. 05 的集合和 08 的多线程是面试重点，值得多花时间。
5. 06 的 GUI 属于可选拓展，时间紧张时可以跳过，不影响后续学习。
6. 09 的反射与动态代理是理解 Spring 的关键，学完 JavaWeb 后可以回来重读。
