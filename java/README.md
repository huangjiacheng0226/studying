# Java 学习笔记

本目录共 10 篇，是一份从零开始、按入门顺序编排的 Java 基础笔记：第 00 篇是学习总纲，后面 9 篇按知识点分类。整体路线是先把语法和面向对象打牢，再往上走常用 API、集合与函数式编程，最后到异常、并发、网络和反射这些进阶话题。

## 篇目清单

| 编号 | 标题 | 主要内容 |
| --- | --- | --- |
| 00 | Java 零基础学习总纲 | 学习路线、知识地图、每阶段的目标 |
| 01 | 开发环境与基础语法 | JDK 安装与环境配置、第一个程序、变量与数据类型、运算符基础 |
| 02 | 运算符、流程控制、数组与方法 | 各类运算符、if 与 switch、循环、数组、方法定义与调用 |
| 03 | 面向对象与字符串 | 类与对象、封装继承多态、构造方法、String 与 StringBuilder |
| 04 | 常用 API 与正则表达式 | 包装类、日期时间、Math、System、正则表达式 |
| 05 | 数据结构、Lambda 与集合 | 常见数据结构、List / Set / Map 三大集合体系、Lambda 表达式 |
| 06 | GUI 与 Stream 函数式编程 | 图形界面基础、Stream 流的中间操作与终端操作 |
| 07 | 异常与 IO 流 | 异常体系与处理、File、字节流与字符流、缓冲流与转换流 |
| 08 | 多线程与网络编程 | 线程的创建与状态、线程安全与锁、线程池、Socket 网络编程 |
| 09 | 反射与动态代理 | Class 对象、反射操作成员、注解、动态代理 |

## 学习路线

| 阶段 | 篇目 | 目标 |
| --- | --- | --- |
| 语法入门 | 01 - 02 | 能写出带分支、循环和方法的基本程序 |
| 面向对象 | 03 | 能用类和对象描述业务，理解三大特性 |
| 基础类库 | 04 - 05 | 熟练使用常用 API 和三大集合 |
| 进阶语法 | 06 - 07 | 会用 Lambda 与 Stream，能正确处理异常和文件读写 |
| 高阶主题 | 08 - 09 | 理解并发与网络，看懂框架底层的反射和代理 |

## 笔记特点

- 第 00 篇的总纲建议最先读，它交代了整套笔记的组织逻辑。
- 每个语法点先给例子再解释规则，避免先堆概念。
- 面向对象、集合、并发这三块是后面 JavaWeb 和框架的地基。

## 阅读建议

1. 00 篇先看一遍，建立整体印象，不必记住细节。
2. 01 到 03 必须按顺序读并动手敲，这是所有后续内容的前提。
3. 05 的集合和 08 的多线程是面试重点，值得多花时间。
4. 09 的反射与动态代理是理解 Spring 的关键，学完 JavaWeb 后可以回来重读。
