# Linux 学习笔记

本目录共 18 篇，按“先认识、再命令、后实用、最后上线”的顺序编排，面向刚接触 Linux 的初学者。前几篇解决“Linux 是什么、怎么把它跑起来”，中间讲命令和权限，06 到 12 按任务类别整理日常最常用的操作，13 之后转向脚本化、系统管理与运维实战，把零散命令串成能上线的流程。

## 内容结构

| 部分 | 篇目 | 内容 |
| --- | --- | --- |
| 初识 Linux | 01 - 03 | 操作系统与 Linux 概念、VMware 虚拟机与远程连接、WSL 与虚拟机快照 |
| 基础命令 | 04 | 目录结构与路径、命令基础格式、文件与目录操作、查找、管道、重定向 |
| 用户和权限 | 05 | root 用户与切换、用户和用户组管理、权限查看与修改 |
| 实用操作 | 06 - 12 | 快捷键与软件安装、日期时区、网络与固定 IP、网络传输与端口、进程与主机状态、环境变量与文件传输、压缩与解压 |
| 进阶技能 | 13 - 16 | Shell 脚本与定时任务、文本处理三剑客、磁盘管理与文件系统、SSH 进阶与文件同步 |
| 运维实战 | 17 - 18 | 日志查看与故障排查、服务部署实战 |

## 笔记特点

- 前三篇每篇末尾有自测题，用来确认基础概念是否真的理解。
- 第 04 篇开始每篇末尾有本篇知识点总结，方便复习。
- 命令讲解按“这个命令解决什么问题”组织，而不是罗列参数。
- 13 篇之后转向脚本化、系统管理与运维实战：13 到 14 让命令自动化，15 到 16 管好磁盘与远程通道。

## 阅读建议

1. 如果只是想在 Windows 上快速用上 Linux，可以直接看 03（WSL）。
2. 如果准备用虚拟机做完整练习，看 02 和 03 的 VMware 部分。
3. 04 和 05 是核心，命令和权限是后面一切操作的地基。
4. 06 到 12 不必按顺序死读，按需要查即可，适合当作速查手册。
5. 15 解决“磁盘满了怎么办、新加一块盘怎么用”，适合在做部署和排障之前先看一遍。
6. 13（脚本）与 14（文本处理）配合使用，能把重复劳动变成一条命令或一个定时任务。
7. 16 到 18 是一组：先把远程连接与文件同步弄稳，再学日志排障，最后按 18 的流程完整部署一次服务。
8. 17 适合当排障手册随时翻，遇到“服务访问不了”就先照它的顺序走一遍。
