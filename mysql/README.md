# MySQL 学习笔记

本目录共 18 章正文加 1 篇目录，面向 MySQL 初学者，以 MySQL 8.0 为准。内容按入门、核心、进阶三段编排：先把建库建表和查询打牢，再看索引和优化这些性能话题，最后进入主从复制、分库分表这类集群内容。

完整的篇目清单和阅读顺序见 [`00-目录.md`](./00-目录.md)。

## 内容结构

| 部分 | 篇目 | 内容 |
| --- | --- | --- |
| 入门 | 01 - 03 | 数据库概念、安装与连接；SQL 的 DDL / DML / DQL / DCL、约束与多表查询；事务、ACID、并发问题与隔离级别 |
| 核心 | 04 - 14 | 存储引擎；慢查询与 EXPLAIN；索引与 B+Tree；SQL 优化；视图、存储过程与触发器；锁；InnoDB 引擎与 MVCC；MySQL 管理；日志 |
| 进阶 | 15 - 18 | 主从复制；分库分表；读写分离；权限速查与常用技巧 |

## 笔记特点

- 第 02 章 SQL 是篇幅最大的一章，也是唯一必须动手敲的一章。
- 索引部分（第 06 章）是面试和实际工作的双重重点，建议配合真实数据用 EXPLAIN 验证。
- 正文中的流程示意图统一使用 Mermaid 绘制。
- 本目录只保留 Markdown 文档，原始的图片、PDF 和配置文件等附件没有纳入仓库。

## 阅读建议

1. 先在本地装好 MySQL，跟着 01 到 03 章完成建库、建表、查询和事务练习。
2. 05 到 07 章不要只背结论，配合实际数据量跑 EXPLAIN 才能真正理解。
3. 15 到 17 章需要 Linux、多实例和网络基础，建议掌握单机 SQL 之后再学。
4. 复习时可以直接看 [`00-目录.md`](./00-目录.md) 定位章节。
