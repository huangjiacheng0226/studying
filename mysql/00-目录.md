## 文档说明

本目录仅保留 Markdown 学习文档。原始图片、PDF、配置文件等附件未纳入仓库；正文中的流程示意统一使用 Mermaid，打开支持 Mermaid 的 Markdown 阅读器即可查看。

## 学习建议

1. 先在本地安装 MySQL，跟随第 1～3 章完成建库、建表、查询和事务练习。
2. 第 5～7 章配合实际数据量使用 `EXPLAIN`，不要只背索引规则。
3. 第 15～17 章需要 Linux、多实例和网络基础，可在掌握单机 SQL 后再学习。
4. 第 19～21 章属于分布式与运维话题，建议在分库分表与主从复制之后按需阅读；第 22 章的设计规范适合在建表之前先看一遍。
