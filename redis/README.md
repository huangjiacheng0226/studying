# Redis 学习笔记

本目录共 16 篇，分成三部分：01 到 03 是快速入门，04 到 09 是基于「黑马点评」项目的 Redis 实战，10 到 16 是原理与进阶。入门部分讲清楚 Redis 是什么、数据类型怎么用；实战部分用真实业务场景把缓存、分布式锁、消息队列串起来；原理部分补上持久化、高可用、内存管理、底层结构与多级缓存。

## 内容结构

| 部分 | 篇目 | 内容 |
| --- | --- | --- |
| 快速入门 | 01 - 03 | Redis 的定位与安装、数据类型与常用命令、Java 客户端与典型应用场景 |
| Redis 实战 | 04 - 09 | 黑马点评项目的一条连续演进线：短信登录与缓存、优惠券秒杀与分布式锁、秒杀优化与消息队列、探店关注与 Feed 流、GEO 签到与 UV 统计、流程图与版本演进 |
| 原理与进阶 | 10 - 16 | 持久化、高可用与集群、过期与内存淘汰、最佳实践、底层数据结构、网络模型与通信协议、多级缓存与缓存同步 |

## 笔记特点

- 入门和原理部分用大量对比表格说明数据类型的差异、持久化方案和高可用方案的取舍，方便选型。
- 实战部分按“先出现问题、再解决问题”的顺序推进，能看清一个方案是怎么被逼出来的。
- 第 09 篇专门做横向对比和流程梳理，适合复习时先看这一篇找回全局。
- 原理部分从底层结构讲到网络模型，是把前面命令层的经验接到实现层的桥梁。

## 阅读建议

1. 01 到 03 必须按顺序读，这是后面实战的前提。
2. 04 到 08 是同一个项目（黑马点评）的连续演进，建议按顺序看，能体会到方案迭代的过程。
3. 05 的分布式锁和 06 的消息队列是这套笔记里最值得反复看的两个主题。
4. 复习时先看 09 的对比表和流程图，再回到具体章节补细节。
5. 10 到 16 的原理部分建议在实战之后读，遇到具体问题时再按篇回查。
6. 12 的过期与内存淘汰、13 的最佳实践是生产排障时最常用的两篇。
