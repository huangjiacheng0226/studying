# Redis 学习笔记

本目录共 9 篇，分成两部分：前三篇是 Redis 快速入门，后六篇是基于「黑马点评」项目的分布式缓存实战。入门部分讲清楚 Redis 是什么、五种数据类型怎么用；实战部分用真实的业务场景把缓存、分布式锁、消息队列这些概念串起来。

## 内容结构

| 部分 | 篇目 | 内容 |
| --- | --- | --- |
| 快速入门 | 01 - 03 | Redis 是什么与安装、五种数据类型与常用命令、Java 客户端与典型应用场景 |
| 项目实战 | 04 - 09 | 短信登录与缓存、优惠券秒杀与分布式锁、秒杀优化与消息队列、达人探店与 Feed 流、附近商户与 UV 统计、缓存问题对比与版本演进 |

## 篇目清单

| 编号 | 标题 | 主要内容 |
| --- | --- | --- |
| 01 | 基础认识与环境准备 | Redis 是什么、主要特点、安装与客户端、与关系型数据库的区别、Key 命名规范 |
| 02 | 数据类型与常用命令 | String、Hash、List、Set、Sorted Set 五种类型与通用命令 |
| 03 | 应用实践与总结 | Java 客户端、Redis 作为缓存 / 计数器 / 简单队列、过期时间与数据生命周期、命令速查表 |
| 04 | 短信登录与缓存 | 用 Redis 存验证码与登录状态、商户查询缓存、缓存穿透与雪崩的处理 |
| 05 | 优惠券秒杀与分布式锁 | 秒杀基础、库存超卖问题、一人一单、用 Redis 实现分布式锁 |
| 06 | 秒杀优化与消息队列 | 秒杀流程优化、Redis 消息队列、异步秒杀下单 |
| 07 | 达人探店与好友关注 | 达人探店、好友关注、Feed 流的实现 |
| 08 | 附近商户、签到与 UV 统计 | GEO 实现附近商户、BitMap 实现用户签到、HyperLogLog 做 UV 统计 |
| 09 | 流程图与版本演进 | 三类缓存问题对比、缓存一致性决策流程、方案演进、Redis 与依赖版本变化 |

## 笔记特点

- 入门部分用大量对比表格说明五种数据类型的差异和适用场景，方便选型。
- 实战部分按“先出现问题、再解决问题”的顺序推进，能看清一个方案是怎么被逼出来的。
- 第 09 篇专门做横向对比和流程梳理，适合复习时先看这一篇找回全局。

## 阅读建议

1. 01 到 03 必须按顺序读，这是后面实战的前提。
2. 04 到 08 是同一个项目（黑马点评）的连续演进，建议按顺序看，能体会到方案迭代的过程。
3. 05 的分布式锁和 06 的消息队列是这套笔记里最值得反复看的两个主题。
4. 复习时先看 09 的对比表和流程图，再回到具体章节补细节。
