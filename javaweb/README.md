# JavaWeb 学习笔记

本目录是黑马程序员 JavaWeb 课程的完整学习笔记，按课程顺序编号。内容从最前端的 HTML/CSS 一路讲到项目部署，中间贯穿一个完整的实战项目：Tlias 智能学习辅助系统。

## 学习路线

| 阶段 | 篇目 | 内容 |
| --- | --- | --- |
| 前端基础 | 01 - 02 | HTML 页面结构与 CSS 样式；JavaScript 语法、Vue 基础、Ajax 异步请求 |
| 后端基础 | 03 - 06 | Maven 依赖管理与生命周期；Spring Boot 入门与 HTTP 协议；三层架构与 IoC/DI；MySQL 与 MyBatis |
| 后端实战 | 07 - 11 | 部门管理 CRUD；员工管理的多表查询与分页、新增与事务、文件上传、修改删除与统计；接口文档 |
| 登录认证与进阶 | 12 - 14B | Cookie / Session / JWT 登录认证与拦截器；AOP 面向切面编程；Maven 高级；Spring Boot 自动配置原理 |
| 前端实战 | 15 - 18 | Vue 工程化与 Element Plus；Tlias 前后端分离的部门管理与员工管理页面 |
| 项目部署 | 19 - 20 | Linux 下用 systemd 与 Nginx 部署；Docker 镜像与容器化部署 |

## 笔记特点

第 12 篇之后的进阶篇目采用了统一的教学结构，阅读时可以留意：

- 每篇开头有学习目标与前置知识，明确学完应该会什么。
- 概念先讲清是什么、为什么需要，再给代码。
- 涉及流程和链路的地方配 Mermaid 流程图。
- 每篇末尾有小白易错点和练习清单，方便自查。

## 阅读建议

1. 01 到 06 是基础，建议按顺序读，不要跳。
2. 07 到 10 是同一个项目（Tlias）的后端部分，最好对着代码一起看。
3. 12 的登录认证是后端的分水岭，JWT 和拦截器这两块值得反复看。
4. 19 和 20 的部署需要先有 Linux 基础，可以配合仓库中的 [`linux`](../linux) 目录一起读。
